Browser ini tidak mendukung Web Bluetooth.
Gunakan Chrome atau Edge di macOS, Windows, atau Android. Safari dan Firefox belum mendukungnya, termasuk di iPhone dan iPad. Untuk iPhone, pakai aplikasi BLE Serial HM-10.
Halaman ini harus dibuka lewat HTTPS atau localhost.
Web Bluetooth menolak bekerja pada file://. Lihat web/README.md untuk cara menjalankannya.
